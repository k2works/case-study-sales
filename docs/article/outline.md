# 販売管理システムのケーススタディ（Java版）- アウトライン

## 書籍概要

**タイトル案**: 販売管理システムのケーススタディ - Java + Spring Boot によるエンタープライズアプリケーション開発

**対象読者**:
- Java による Web アプリケーション開発経験者
- エンタープライズシステム開発に興味のあるエンジニア
- TDD/XP を実践したい開発者
- ドメイン駆動設計（DDD）を学びたいエンジニア

**本書の特徴**:
- 実際の開発プロジェクト（13ヶ月間）を題材にした実践的な内容
- 広域データモデリング先行によるデータモデル妥当性
- 段階的な機能開発を通じて学ぶアーキテクチャ設計
- TDD とリファクタリングの実践例
- 貧血ドメインモデルからリッチドメインモデルへの進化過程

**執筆方針**:
- ダイアグラムはplantumlを使う
- TDDに即した実コード解説によりドキュメントからプロジェクトを再現できる構成にする
